## 1. Categories & Ledger Enhancements

### [#30 Manage categories](https://github.com/saadh393/ledger-keeper-mobile/issues/30)
- **Status:** `status: ready`
- **Goal:** Users can view income and expense categories, add custom categories, and delete custom ones from the Ledger ⋯ menu.
- **Key Acceptance Criteria:**
  - Ledger top bar ⋯ menu opens Categories screen with Income and Expense tabs.
  - Lists categories from `GET /api/categories` with server color dot and name.
  - Built-in categories (`system: true`) show "Built-in" label and disable delete.
  - "Add category" sheet validates name (trimmed, 1–40 chars, case-insensitive uniqueness check per kind) and sends `POST /api/categories`.
  - Deleting user category shows confirmation: *"Existing transactions keep this category name"* and sends `DELETE /api/categories/:id`.
  - Categories query is shared with transaction form picker (#29).
- **Constraints:**
  - Backend: `GET/POST /api/categories`, `DELETE /api/categories/:id`.
  - Feature directory: `src/features/categories/`.

### [#62 Rename categories](https://github.com/saadh393/ledger-keeper-mobile/issues/62)
- **Status:** `status: analysis`
- **Goal:** Users can rename custom categories without breaking past transaction histories.
- **Key Acceptance Criteria:**
  - Long-press or ⋯ menu on a user category in the Categories screen has "Rename".
  - Rename bottom sheet prefilled with current name; validates uniqueness.
  - Saves via `PATCH /api/categories/:id { name }`.
  - Built-in categories cannot be renamed.
- **Constraints:**
  - Depends on backend supporting category renaming across transactions, items, and plans in a single database transaction.

### [#75 Ledger summary strip: show exact value on long-press](https://github.com/saadh393/ledger-keeper-mobile/issues/75)
- **Status:** `enhancement`, `status: analysis`
- **Goal:** Allow sighted users to see unrounded figures from the compact summary strip on long-press.
- **Key Acceptance Criteria:**
  - Long-pressing a summary strip cell shows its exact value (e.g., *"Income ৳12,34,56,789.00"*) in a tooltip/snackbar.
  - Does not change strip height or shift layout.
  - Reuses existing `formatStat`.

## 2. Loans & Debts

### [#31 Loans list](https://github.com/saadh393/ledger-keeper-mobile/issues/31)
- **Status:** `status: ready`
- **Goal:** Display lent and borrowed balances for the active book, separate from income/expense.
- **Key Acceptance Criteria:**
  - Drawer → Loans screen shows header totals: "Owed to you" (lent) and "You owe" (borrowed).
  - Open / Settled / All tabs load `GET /api/books/:bookId/debts?status=...`.
  - Row shows counterparty, direction (Lent/Borrowed), outstanding balance (`amount − repaid`), original amount, and due date.
  - Overdue loans in Asia/Dhaka highlighted with warning tone.
  - Tapping row expands repayment history via `GET /api/books/:bookId/debts/:id`.
  - Paged FlashList with pull-to-refresh.
- **Constraints:**
  - Feature directory: `src/features/loans/`.

### [#32 Add and settle loans](https://github.com/saadh393/ledger-keeper-mobile/issues/32)
- **Status:** `status: ready`
- **Goal:** Create loans, record repayments, and mark loans settled.
- **Key Acceptance Criteria:**
  - "Add loan" sheet: Person name, Direction (Lent/Borrowed), Amount, Due date (optional), Note (optional).
  - "Record repayment" sheet: Repayment amount (≤ remaining balance), Date (not future).
  - "Mark settled" action with confirmation.
  - Full repayment automatically marks loan as settled.
  - Loans and book totals cache invalidated after mutations.
- **Constraints:**
  - Backend: `POST /api/books/:bookId/debts`, `POST .../debts/:id/repayments`, `POST .../debts/:id/settle`.

### [#63 Loan and installment cards in the Assistant](https://github.com/saadh393/ledger-keeper-mobile/issues/63)
- **Status:** `status: ready`
- **Goal:** Display structured loan and installment cards inside the Assistant chat feed when generated by AI.
- **Key Acceptance Criteria:**
  - `debt` card: Person, direction, outstanding, original, repaid, due date / overdue tag, "Settled" status badge.
  - `debt-list` card: Summary totals and paginated rows (collapses > 10 rows).
  - Quick "View in Loans" / "View in Installments" links.
  - Screen reader accessibility labels summarizing card contents.

## 9. Android Native Auto-Capture & Inbox

### [#50 Notification listener native module](https://github.com/saadh393/ledger-keeper-mobile/issues/50)
- **Status:** `status: ready`
- **Goal:** Native Android module declaring a `NotificationListenerService`.
- **Key Acceptance Criteria:**
  - Expo config plugin declaring service in `AndroidManifest.xml`.
  - JS bridge methods: `isAccessGranted()` and `openAccessSettings()`.
  - Inactive unless explicit user permission is granted.

### [#51 Native capture filter](https://github.com/saadh393/ledger-keeper-mobile/issues/51)
- **Status:** `status: ready`
- **Goal:** On-device Kotlin filter ensuring only financial transactions are recorded.
- **Key Acceptance Criteria:**
  - Matches debit/credit keywords in English & Bangla for bKash, Nagad, and local banks.
  - Strict exclusion for OTPs and two-factor codes.
  - Deduplication via hash `(app + text + minute)`.
  - Rejected notifications are discarded immediately and never stored.

### [#52 Encrypted capture queue and upload](https://github.com/saadh393/ledger-keeper-mobile/issues/52)
- **Status:** `status: ready`
- **Goal:** Store captured raw notifications in encrypted local DB and sync to backend.
- **Key Acceptance Criteria:**
  - SQLite database encrypted with Android Keystore.
  - Syncs to `POST /api/books/:bookId/captures` on app open and periodic background task.
  - Discards local entries only after 200/201 response.

### [#53 Auto-capture consent screen](https://github.com/saadh393/ledger-keeper-mobile/issues/53)
- **Status:** `status: ready`
- **Goal:** Mandatory privacy disclosure before triggering system permission prompt.
- **Key Acceptance Criteria:**
  - Explains: *Why*, *What we read*, *What we never read or store*, *How to disable*.
  - "Continue" routes to Android Notification Access settings.

### [#54 Choose source apps](https://github.com/saadh393/ledger-keeper-mobile/issues/54)
- **Status:** `status: ready`
- **Goal:** Let users select specific installed apps to monitor.
- **Key Acceptance Criteria:**
  - Queries installed packages and highlights detected financial apps (bKash, Nagad, bank apps).

### [#55 Auto-capture status and turn off](https://github.com/saadh393/ledger-keeper-mobile/issues/55)

- **Goal:** Transparency and kill-switch for notification tracking.
- **Key Acceptance Criteria:**

### [#56 Detected transactions inbox](https://github.com/saadh393/ledger-keeper-mobile/issues/56)
